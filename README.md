# Mini Projetos Indústria 2026

Repositório dedicado ao desenvolvimento de **pequenas soluções em Python voltadas para automação, produtividade e necessidades do ambiente industrial e logístico**.

A proposta é transformar problemas operacionais do dia a dia em ferramentas simples, práticas e automatizadas, utilizando programação para reduzir tarefas manuais, facilitar cálculos e apoiar processos.

## Objetivo

Desenvolver e reunir pequenos sistemas que possam ser aplicados em situações reais da indústria, logística e operações, explorando conceitos de:

* Python
* Automação de processos
* Cálculos e indicadores de produtividade
* Logística e operações
* Geração de QR Codes
* Desenvolvimento de aplicações
* Manipulação de dados
* Processamento de informações através de inputs

## Projetos

### 01 — Cálculo de Produtividade

Sistema desenvolvido para automatizar cálculos de produtividade a partir de informações fornecidas pelo usuário.

**Principais informações:**

* Quantidade produzida
* Horas trabalhadas
* Número de colaboradores
* Produtividade
* Indicadores de desempenho

### 02 — Gerador de QR Code

Aplicação desenvolvida em Python para geração automatizada de QR Codes a partir de informações inseridas pelo usuário.

Pode ser utilizada como base para aplicações de identificação, rastreabilidade, produtos, equipamentos, endereçamento e processos logísticos.
